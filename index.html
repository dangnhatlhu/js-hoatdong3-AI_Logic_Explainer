Đoạn mã

Điều khiển modal đăng ký

script.js 
// Lấy phần tử menu đăng ký và modal tương ứng
const registerMenu = document.getElementById('registerMenu');
const registerModal = document.getElementById('registerModal');
const closeModalBtn = document.getElementById('closeModalBtn');

if (registerMenu && registerModal) {
    // Sự kiện khi click hoặc rê chuột vào menu Đăng ký
    registerMenu.addEventListener('click', function(e) {
        e.preventDefault();
        registerModal.style.display = 'block'; // Hiển thị modal
    });
}

if (closeModalBtn && registerModal) {
    closeModalBtn.addEventListener('click', function() {
        registerModal.style.display = 'none'; // Đóng modal
    });
}

💡 Gợi ý: Hãy lần theo thứ tự: tìm phần tử → kiểm tra điều kiện → chờ sự kiện → thay đổi giao diện.

Tự kiểm tra luồng chạy

Menu trang mẫu Đăng ký

Nhấn “Đăng ký”, quan sát modal xuất hiện, sau đó nhấn nút × để đóng.

Luồng chạy bằng ngôn ngữ tự nhiên

  1. 1 Tìm phần tử: JavaScript lấy menu, modal và nút đóng từ HTML bằng ID.
  2. 2 Kiểm tra an toàn: Chỉ gắn sự kiện mở khi tìm thấy cả menu lẫn modal.
  3. 3 Mở modal: Khi nhấn menu, ngăn liên kết điều hướng rồi đặt display thành block.
  4. 4 Đóng modal: Khi nhấn nút ×, đặt display thành none.
Điểm cần nhớ: addEventListener đăng ký việc cần làm khi có sự kiện; đoạn callback chỉ chạy sau khi người dùng nhấn.
